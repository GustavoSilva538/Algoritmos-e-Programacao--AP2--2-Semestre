# 📚 Algoritmos e Programação II (AP2) - 2º Semestre

![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white)

Este repositório foi criado para armazenar e organizar todo o material de estudo, práticas e entregas acadêmicas da disciplina de **Algoritmos e Programação II**, cursada no 2º semestre do curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo principal deste repositório é documentar a evolução no aprendizado de lógica de programação, estruturas de dados e orientação a objetos utilizando a linguagem **Java**, que compõe 100% do código deste projeto[cite: 3].
